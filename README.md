# Homebase
A hyperlocal social networking platform, connecting people in the same geographic neighborhood, apartment complex, or condominium. Homebase also users in apartment complexes and condos to interact with landlords and pay rental fees, whereas users with owned homes can interact with local community members.

The goal is to create a one-stop shop for social networking and apartment management.

This will be achieved through a web application.

# Functional Requirements
1. User shall be able to create, update, delete account
2. User shall be able to create, edit, delete posts
3. User shall be able to add items for sale to marketplace
4. User shall be able to create and join homebases
5. User shall be able to invite users to homebase, kick user from homebase
